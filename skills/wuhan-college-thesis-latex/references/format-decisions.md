# 文经管 LaTeX 模板：规范决策与实现计划

目标：依据用户指定的武汉学院原DOC后半部“文经管类”完整示例，建立可编译、可复用并带证据检查的LaTeX模板和Skill。不修改原论文、数据或旧模板。

## 依据与裁决

1. 学校明文尺寸/字号/编号为约束；文经管示例决定封面、页眉、签署区和栏目结构。原件注解、占位年份、PAGE字段缓存、红色提示和意外分页不复制进论文。
2. 原DOC的文字提取、LibreOffice原生DOCX结构、原DOC直接PDF三者分开记录。textutil件只作内容索引；不得据其页面尺寸认定学校采用Letter。
3. 正文及通常栏目1.25倍、声明/封面1.5倍、参考文献单倍、致谢固定23磅。使用无网格的Word行距试样标定当前字体的基线，不将ctex默认行距再乘1.25。LO原DOC的39/46.8/31.2pt网格膨胀不复制。
4. 正文16pt一级标题；引论/结语18pt；摘要/目录/文献/附录18pt；声明22pt。两字标题中间明确空两汉字。
5. 页眉9pt校名+0.75pt线，距纸上约15mm；正文页脚9pt，距下约17.5mm。声明及题名不印页码；中摘/英摘/目录各重起1，正文再重起1后连续。采用自动页码和自动目录，不复制原件缓存。
6. 文献采用明文和PDF可见的首行缩2字、续行再悬挂2.2字；记录原生字符属性直读与实际渲染存在差异。不因套格式改文献事实、排序或引用。
7. 首选SimSun/SimHei/FangSong/KaiTi和TNR；本机缺少部分Windows字体，允许明确记录的本机简宋/黑体/仿宋/楷体映射；不把替代字体说成微软宋体，不随模板打包商业字体。严格字体模式供装好指定字体后使用。
8. 完成时间、声明手写签名/日期、致谢正文留空；个人信息仅在本论文配置中，通用Skill不含姓名学号。
