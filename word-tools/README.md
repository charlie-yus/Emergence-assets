# Word 排版

| 文件 | 用途 | 谁用 |
|---|---|---|
| `layout-rules.md` | Word 版面规则：表格内容由作者定、先文后图、一页最多两张图、目录对齐、留白不超过四分之一页、交付前逐页检查 | 所有用 Word 排版的人和 AI，**排版前先读** |
| `fix_layout.py` | 自动修页底留白：渲染 PDF，找出底部空白超过 1/4、且下一页以图开头的页，把图后面的一段正文移到图前；移不动时把图缩小，但不低于 80% | 能运行代码的 AI（可选） |

## fix_layout.py

依赖：LibreOffice（命令 `soffice`；也可用环境变量 `SOFFICE` 指定路径）、Python 包 `python-docx`、`pymupdf`。

```bash
python3 fix_layout.py 论文.docx 输出目录
```

- 只调整正文段落和图的位置、大小，不改文字内容。
- 每处改动记录在 `输出目录/留白修复记录.json`。
- 图题要写成“图1 ……”的形式，脚本靠它识别图。
- 中文渲染缺字时，在脚本旁边放一个 `fonts.conf`，写明本机中文字体所在的目录。
- 跑完仍要**在 Word 里逐页看一遍**，最终版到 Windows 电脑上打开检查。
